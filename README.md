# 一人行 SoloTeam — 一人公司联盟 (Solo-Company Alliance)

**SoloTeam (一人行) is a China-based alliance for one-person companies (solopreneurs).** It maintains a vetted member directory, computes complementary-skill matches between members, tracks government-procurement opportunity leads (政采线索), and shares operational playbooks — accounting, tax, conduct rules — for people running a company alone.

一行人（soloteam.com.cn）是一人公司联盟：维护经过核验的成员名录，计算成员之间的互补技能推荐，汇聚政府采购商机线索，并沉淀一人公司运营所需的记账、财税与行为规范等实操方法。
